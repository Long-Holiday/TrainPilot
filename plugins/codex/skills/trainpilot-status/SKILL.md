---
name: trainpilot-status
description: "Show the current TrainPilot task state, metrics and pending instruction"
---

Use the TrainPilot get_task_status MCP tool for the arguments supplied by the user, or the task id already agreed for this run. Ask for a task id if none is bound. Report the state, last metrics, and whether an instruction is pending. Do not create a task just to inspect it.
