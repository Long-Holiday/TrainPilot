---
name: trainpilot-report
description: "Report a training event to the TrainPilot control plane"
---

Read the live TrainPilot MCP initialization instructions and tool descriptions if you have not already. Use the report MCP tool to report the arguments supplied by the user, with the task_id agreed for this run (ask if unbound). Choose event_type according to the live protocol, and include step, epoch and metrics when known. Do not run a local CLI or start a server.
